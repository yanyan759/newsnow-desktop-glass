# NewsNow Desktop Glass

このリポジトリは [newsnext/newsnow](https://github.com/newsnext/newsnow) を改造した非公式の Windows デスクトップ版です。ニュース集約機能は ourongxing と上流のコントリビューターによるものです。本リポジトリではデスクトップへの埋め込み、サイズ変更、壁紙・アイコンの屈折表現を追加しています。

インストール手順と制限事項は [README（中国語）](README.md) を参照してください。受領したオリジナルの日本語 README は [こちら](docs/upstream/README.ja-JP.md) に保存しています。
