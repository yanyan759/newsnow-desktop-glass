# NewsNow Desktop Glass（中文说明）

本仓库是基于 [newsnext/newsnow](https://github.com/newsnext/newsnow) 改装的第三方 Windows 桌面版，非官方客户端。新闻聚合基础来自原作者 ourongxing 及上游贡献者；桌面嵌入、缩放与背景折射由本仓库增加。

完整的功能、安装、限制和来源说明请看 [项目 README](README.md)。收到的原版中文文档保留在 [docs/upstream/README.zh-CN.md](docs/upstream/README.zh-CN.md)，最新上游说明以原仓库为准。
