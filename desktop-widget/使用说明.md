# NewsNow 桌面插件

双击桌面「NewsNow 新闻卡片」即可启动。程序自动启动新闻服务，不需要打开终端。然后回到桌面，即可看到贴在桌面上的新闻卡片。

- 拖动上沿「⠿ NewsNow 桌面新闻」移动卡片。
- 拖动四边或四角调整大小；右下角有缩放标记。位置和尺寸会自动保存。
- 窄卡片显示单列，拉宽自动显示多列；缩短时可在新闻列表中滚动。最小大小为 280×240。
- 点击右上角「⋯」打开菜单，可恢复默认大小、刷新、隐藏或完全退出。
- 右下角系统托盘也有图标；右键打开设置菜单。隐藏后点击托盘图标或再次双击桌面快捷方式恢复。
- 卡片属于 Windows 桌面层，不占任务栏应用位置，打开其他软件时会被正常遮挡。重新打开快捷方式不会把卡片强行置顶，请回到桌面查看。
- 「完全退出」只停止插件自己启动的新闻服务。
- 新闻详情用系统默认浏览器打开。
- 「最热」前三项依次为：36氪、GitHub、华尔街见闻。
- 桌面卡片使用背景折射玻璃：当前壁纸和桌面图标会透过卡片显示，曲面边缘产生拉伸、折射、轻微色散和反光；新闻文字保持清晰。
- 拖动时取景位置跟随卡片，桌面图标与静态壁纸变化约每 2 秒检测一次；未变化时不重复上传纹理。取景在本机内存内处理，不上传或保存桌面画面。
- 背景视觉透明不代表鼠标穿透，新闻区域仍接收阅读点击。当前适配本机静态壁纸；动态壁纸视频不支持逐帧折射。显卡上下文失效时使用半透明后备，可通过刷新恢复。
- 没有设置开机自动启动。重启电脑后双击桌面快捷方式即可。

这是通过 Win32 挂载到桌面图标宿主的桌面插件。请拖到桌面空白处；卡片占据自己的矩形区域，不会自动重新排列已有的桌面图标。

如果 Windows 资源管理器更新后桌面挂载失效，可在托盘菜单选择「重新贴到桌面」。插件也会定期检测宿主是否仍然存在。不同 Windows/Explorer 版本可能需要调整挂载适配。

程序依赖当前项目目录、生产构建和 `desktop-widget/config.json` 指定的 Node，请不要单独移动/删除它们。首次安装时按项目 README 写入本机 Node 路径，若移动 Node 则更新配置。更新网页源码后，在项目根目录运行 `corepack pnpm build`，再完全退出卡片并重新打开。

卡片和普通浏览器的关注列表各自保存，桌面卡片使用透明玻璃底面与白色文字。每次启动会刷新页面缓存，保留关注等本地设置。卡片状态与日志保存在 `%APPDATA%\NewsNow Desktop Card`，可通过「卡片 → 查看运行日志」打开。

复测命令（在 desktop-widget 目录）：`npm test`。原生与页面集成测试：先完全退出插件，再运行 `node desktop.integration.cjs`；该测试会调整尺寸、测试拖动和遮挡，并生成 `qa` 目录中的截图和报告。

玻璃取景检查：`node --test qa/desktop-capture.test.cjs`。折射条纹和真实图标验收：`node qa/refraction-check.cjs`。这些验收脚本会在本机 `qa` 目录生成截图，正式运行不保存截图。

重新安装桌面外壳时，在 desktop-widget 目录依次运行 `npm ci`、`npm run setup`，按项目 README 创建 `config.json`，再运行 `./install-shortcut.ps1`。安装完成后，日常使用无需重复执行。

当前入口为 `main.cjs` → `desktop-main.cjs`。本插件基于 newsnext/newsnow 改装，项目首页说明了上游来源及 MIT 许可证。
